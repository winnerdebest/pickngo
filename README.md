# PickNGo — Nigerian Bike-Based Delivery & Errand App 🛵🇳🇬

PickNGo is a Nigerian bike-based delivery and errand execution app.

## Repository Structure
- `/backend`: FastAPI backend application, SQLAlchemy ORM models, SQLAdmin portal, and test suite.
- `/admin`: Reserved for standalone custom web admin dashboards (if needed).
- `/mobile`: Reserved for mobile client (Flutter/React Native).
- `AGENT.md`: Living architecture, trust-tier logic, task lifecycle, and decision log.
- `render.yaml`: Infrastructure-as-Code Blueprint for one-click deployment on Render.

For full setup, testing, and deployment instructions, refer to [backend/README.md](file:///c:/Users/pc/Desktop/PICKNGO/backend/README.md).
